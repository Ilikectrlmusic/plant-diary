已连接 GitHub

Ilikectrlmusic / plant-diary

  1. 在 GitHub 创建精细权限密钥 ↗（Fine-grained token）。
  2. 仓库仅选择 plant-diary，将仓库权限中的
    Contents 设为 Read and write。
  3. 将密钥粘贴在下方，连接你的小花园。

默认仅在当前浏览器会话中保留密钥；仅向 GitHub 发送。

A QUIET CORNER OF THE INTERNET

一日一植，
与日子一起生长。

一片刚刚舒展的新叶，一盆窗边安静的绿植，
或是散步时偶然遇见的野花。

每天拍下一株植物，记下它带来的启发与感想。
不需要懂得它的名字，也不必写出漂亮的句子。
只是停下来，看见它，也看见自己。

所有日记保存在你自己的 GitHub 仓库。
公开阅读，连接后编辑。慢慢积累，长成一本日记。
